## 여정
제가 고2일 당시에 개발자 붐이 생겼어서 국비지원, 부트캠프에 관한 여러가지 광고를 봤습니다.

준비는 프론트엔드로 했었고 빠르게 회사에 들어가고 싶어서 독학을 했지만 혼자 공부하는게 쉽지 않았습니다. 공부를 전혀 안한 날이 더 많았습니다.

그 와중에 우울증이 심하게 와서 1년 반 넘게 우울증 약을 먹고 있습니다. 이대로 가만히 있으면 안되겠다 싶어서 용기를 내 백엔드 부트캠프에 지원하게 됐습니다. 

집중력도 떨어지고 생각도 잘 안되고 머릿속으로 구상하는 것도 어렵습니다. 그래도 최선을 다해 백엔드 개발자가 되고 싶습니다.
